SVG_MKR — Image to SVG Converter

A standalone PWA for converting images to SVG vectors with:
- Background removal (magic wand + eraser)
- Color separation / quantization (2-16 colors)
- Filters: hue, saturation, B&W, invert, threshold, halftone
- True SVG tracing via ImageTracer.js
- One-click SVG download

Extracted from 3DDD Studio V1's ImageEditor.tsx.
